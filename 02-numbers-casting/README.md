## Python Chapter 02 — Numbers and Casting ##

    ## About This Chapter

    This chapter covers Python numbers and type casting. It includes working with different numeric types, performing arithmetic operations, and converting values from one data type to another.

## Topics Covered

    ### 1. Numbers (`numbers.py`)

        - Integer (`int`), float (`float`), and complex (`complex`) numbers
        - Arithmetic operators: `+`, `-`, `*`, `/`, `//`, `%`, and `**`
        - Finding absolute values using `abs()`
        - Rounding numbers using `round()`
        - Checking whole-number floats using `is_integer()`

### 2. Type Casting (`casting.py`)

- Converting values using `int()`, `float()`, `str()`, and `complex()`
- Converting strings into numeric values
- Understanding how data types change during conversion
- Understanding that `int()` removes the decimal part instead of rounding

### 3. Exercises (`exercises.py`)

- Practising arithmetic operations
- Taking numeric input from the user
- Converting input into the correct data type
- Performing calculations with converted values
- Printing values and checking their data types using `type()`
