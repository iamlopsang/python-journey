    ## String Methods:

    upper() — converts letters to uppercase

    lower() — converts letters to lowercase

    strip() — removes whitespace from the beginning and end

    replace() — replaces specified text

    split() — separates a string into a list

    isalnum() — checks whether all characters are letters or numbers

    startswith() — checks whether a string starts with specified text

    endswith() — checks whether a string ends with specified text
